# Release Notes — Morfia `v1.0.0-rc.1`

> **Aviso de Release Candidate:** Esta é uma **Release Candidate (`1.0.0-rc.1`)**, destinada a revisão final e validação multiplataforma antes da eventual promoção para `1.0.0` estável.

---

## 1. Apresentação
**Morfia** (*Multimedia Processing Studio*) é uma estação de trabalho multimídia local-first, 100% offline e de código aberto (licença **MIT**) para conversão, compressão, edição de áudio e vídeo, gerenciamento de legendas, filtros, streams e processamento em lote utilizando **FFmpeg** e **FFprobe** externos.

## 2. Principais Funcionalidades
- Inspeção técnica detalhada via FFprobe JSON.
- Conversão (MP4, MKV, H.264, H.265, AAC, stream copy) e compressão dedicada com CRF.
- Ferramentas de áudio com normalização EBU R128 (`loudnorm` em 1 ou 2 passagens), cortes rápidos/precisos, GIFs em 2 passagens, extração periódica de frames e conversão de imagens.
- Concatenação rápida e compatível, gerenciamento/burn-in de legendas, motor tipado de filtros com preview Antes/Depois e editor de streams/metadados.
- Biblioteca compartilhada, fila concorrente persistente com recuperação de tarefas interrompidas (`INTERRUPTED`), histórico, diagnósticos locais sanitizados, tema retrô escuro/claro e suporte a `pt_BR` e `en`.
- Assistente guiado de 9 etapas para configuração dos executáveis externos **FFmpeg** e **FFprobe**.

## 3. Plataformas Efetivamente Validadas vs. Planejadas
- **Validado localmente:** Linux `x86_64` (Fedora Linux 44, OpenJDK 25.0.5, JavaFX 24, FFmpeg 8.1.3).
- **Planejado (ainda não validado em execução nativa):** Ubuntu/Debian `x86_64`, Windows `x86_64`, macOS `arm64` e `x86_64`.

## 4. Artefatos Construídos Localmente (Linux `x86_64`)
- `morfia-1.0.0-rc.1-linux-x64.tar.gz` (distribuição portátil com runtime Java 25 e JavaFX 24 integrados; **não inclui FFmpeg/FFprobe**).
- Consulte os checksums reais em `dist/1.0.0-rc.1/linux-x64/SHA256SUMS.txt` e `dist/1.0.0-rc.1/SHA256SUMS`.

## 5. Instalação e Configuração Inicial (Linux Portátil)
```bash
tar -xzf morfia-1.0.0-rc.1-linux-x64.tar.gz
./morfia/bin/morfia
```
Na primeira abertura, utilize o **Assistente FFmpeg** para detectar ou selecionar manualmente os binários `ffmpeg` e `ffprobe` instalados no seu sistema (consulte [docs/INSTALLATION.md](../INSTALLATION.md)).

## 6. Limitações, Estado Experimental e Avisos de Hardware
- **Aceleração por Hardware (VAAPI):** Depende do suporte de driver e encoder do FFmpeg do sistema operacional; em caso de falha na sondagem real, a aplicação mantém a codificação por software sem mascarar erros.
- **Pacotes RPM/DEB/Windows/macOS:** Não foram gerados localmente nesta máquina (`rpmbuild`, `fakeroot`, WiX e macOS ausentes neste host); sua geração depende de ambiente/runner específico.
- **Assinatura de Código:** Não há assinatura Authenticode (Windows) ou Developer ID/notarização Apple (macOS) configurada para esta release candidate.
