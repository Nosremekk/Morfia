# Release Notes — Morfia `v1.0.0-rc.1`

> **Release Candidate (`v1.0.0-rc.1`)** — Destinada a validação comunitária antes da eventual promoção para `v1.0.0`.

---

## 1. Descrição
**Morfia** (*Multimedia Processing Studio*) é uma estação de trabalho multimídia local-first, 100% offline e de código aberto (licença **MIT**) para conversão, compressão, edição de áudio e vídeo, legendas, filtros, streams e processamento em lote utilizando **FFmpeg** e **FFprobe** externos.

## 2. Plataformas Recomendadas para `v1.0.0-rc.1`
- **Linux (`x86_64` — Fedora & Ubuntu/Debian):** `.tar.gz` portátil, `.rpm` (Fedora) e `.deb` (Ubuntu 24.04 com runtime `jlink` embutido e verificado).
- **Windows (`x86_64`):** `.zip` portátil (com smoke test do launcher `Morfia.exe` aprovado em CI), `.exe` e `.msi` (`0.99.1`, sem assinatura Authenticode).
- **macOS (`arm64` / `x86_64`):** Não incluído nos binários desta RC1 (empacotamento cancelado por timeout no runner `macos-15`).

## 4. Instalação e Configuração Externa do FFmpeg
**Morfia não inclui FFmpeg nem FFprobe nos instaladores.** Instale-os no sistema conforme [docs/INSTALLATION.md](../INSTALLATION.md) e conclua o **Assistente FFmpeg** ao abrir o aplicativo.

## 5. Limitações Conhecidas e Avisos de Assinatura
- **Windows:** Sem assinatura Authenticode; o Windows SmartScreen pode exibir aviso de editor desconhecido. Não desabilite mecanismos de segurança do Windows.
- **macOS:** Sem instalador `.dmg`/`.pkg` nesta RC1.
- **Aceleração por Hardware (VAAPI):** Depende do driver e pacote FFmpeg do sistema; fallback explícito para software quando não funcional.
