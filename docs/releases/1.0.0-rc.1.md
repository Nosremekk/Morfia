# Release Notes — Morfia `v1.0.0-rc.1`

> **Status:** Publicada oficialmente em 21/11/2026 como **Pre-release** pública.  
> **URL da Release:** [https://github.com/Nosremekk/Morfia/releases/tag/v1.0.0-rc.1](https://github.com/Nosremekk/Morfia/releases/tag/v1.0.0-rc.1)

---

## 1. Descrição
**Morfia** (*Multimedia Processing Studio*) é uma estação de trabalho multimídia local-first, 100% offline e de código aberto (licença **MIT**) para conversão, compressão, edição de áudio e vídeo, legendas, filtros, streams e processamento em lote utilizando **FFmpeg** e **FFprobe** externos.

## 2. Plataformas Suportadas nesta Release Candidate
- **Linux (`x86_64`):**
  - Pacote `.tar.gz` portátil com runtime Java 25 embutido.
  - Pacote nativo `.rpm` para Fedora, RHEL e derivados.
  - Pacote nativo `.deb` para Ubuntu 24.04, Debian e derivados (com runtime `jlink` verificado).
- **Windows (`x86_64`):**
  - Arquivo `.zip` portátil com launcher `Morfia.exe` testado em CI.
  - Instalador `.exe` (`0.99.1`, sem assinatura Authenticode).
  - Instalador `.msi` (`0.99.1`, sem assinatura Authenticode).
- **macOS (`arm64` / `x86_64`):**
  - Não incluído nos binários desta RC1 (suporte previsto para a versão v1.0.0 estável).

## 4. Instalação e Configuração Externa do FFmpeg
**Morfia não inclui os binários do FFmpeg nem do FFprobe nos instaladores.**  
Instale-os no sistema conforme as instruções em [docs/INSTALLATION.md](../INSTALLATION.md) e siga o **Assistente FFmpeg** exibido ao iniciar o aplicativo pela primeira vez.

## 5. Limitações Conhecidas e Avisos de Assinatura
- **Windows:** Sem assinatura Authenticode comercial; o Windows SmartScreen pode exibir o aviso usual de desenvolvedor desconhecido. Não é necessário nem recomendado desabilitar os mecanismos de proteção do sistema operacional.
- **macOS:** Sem instalador nativo nesta release candidate.
- **Aceleração por Hardware (VAAPI):** A disponibilidade depende dos drivers e encoders instalados no sistema; fallback transparente para software caso o hardware não responda.
